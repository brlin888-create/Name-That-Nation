# Name-That-Nation
Game to access knowledge of countries shapes as they get progressively better at the game!

This game is extremely fun for anyone who wants to learn to memorize countries by their shape. Additionally, fun facts are present
throughout the game, and there are powerups throughout to enhance the learning experience. This entire game is coded in Java, 
meaning based on code, it was very difficult to make compared to using other programming languages as it was technical. If you 
want to play this game, I suggest you download these files together, then go to powershell and type "javac NameThatNation.java". 
Afterwards, type "java NameThatNation" and a small window should pop up and you will be able to play the game. Since the game utilizes
the reading of files and writing of files, you will need to download these files in order to play the game with all the graphics. 

Have fun and enjoy the learning experience!!!
