# Name-That-Nation
Game to access knowledge of countries shapes as they get progressively better at the game!

This game is extremely fun for anyone who wants to learn to memorize countries by their shape. Additionally, fun facts are present
throughout the game, and there are powerups throughout to enhance the learning experience. This entire game is coded in Java, 
meaning based on code, it was very difficult to make compared to using other programming languages as it was technical.

Before you start playing here is the link for a tutorial on youtube: https://www.youtube.com/watch?v=e_40g-6kNjw

# Quick Start:
If you want to play this game, go to the **releases page**. There I have created a zip file called NameThatNation v1.0.0, where you can download the zip file. 
After downloading the file, you will then be able to access all the necessary files. Clicking on Play.Bat will get you started. 

# Core Features: This is all the technical code explanation summary
Adaptive Graphical User Interface (Swing/AWT)
Built natively on Java's JFrame and JPanel rendering architecture, delivering a locked 960x540 canvas optimized for robust frame stability and zero-lag rendering.

Stateful Visual Animations
Utilizes precise background thread javax.swing.Timer listeners to cycle frame buffers, creating seamless, low-resource world-map animations on the master entry panel.

Dynamic Session Customization Canvas
Features real-time state listeners including interactive JSlider RGB color mixers for instant workspace tinting, a custom JScrollBar matrix for responsive asset scale modulation, and custom JCheckBox filters to sort targeted gameplay data.

Dataset Compilation
Evaluates multi-tier data parameters across 7 distinct global continent tags. The engine scans structural raw .txt registries using robust input streams and try-catch safety parameters to assemble unique country queues.

Streaks Reward and Milestone System
Tracks player accuracy metrics to unlock 4 progressive, state-changing power-ups mapped to strict consecutive correct-answer criteria:
• Freeze Time (3-Streak Milestone): Activates a separate cooldown timer overlay and increments the main count countdown by 30 seconds.
• Strategic Skip (5-Streak Milestone): Forgoes points to advance the application sequence past a complex entry without penalizing lifelines.
• Extra Life (7-Streak Milestone): Replenishes an active user lifeline buffer (capped strictly at a 3-heart maximum threshold).
• Double Points (10-Streak Milestone): Applies a 2x modifier payload to all subsequent base-point computations.

Hints and Modal Windows
Spawns context-isolated sub-frames to query custom documentation indices. This structure isolates and extracts relevant data modules (language, geography, landmarks) while programmatically protecting the core answer key string.

Local Persistence Modules and Analytics
Tracks real-time session telemetry including time-elapsed statistics, calculation breakdowns, and accuracy ratios. Score records are appended directly to local leaderboards, while a 17-part boolean vector records historical achievement flags across distinct gameplay sessions.
